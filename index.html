Modeller ve anahtarlar

API anahtarlarını Android'in güvenli anahtar deposunda sakla. Her model kimliğini ihtiyaç duyduğunda değiştirebilirsin.

Güvenlik: Android uygulamasında anahtarlar KeyStore tabanlı şifreli depoda saklanır. Yine de ele geçirilmiş/root erişimli bir cihaz veya uygulama incelemesi risktir. Kod depomuzda anahtarın yok; bu ekrana yalnızca kendi anahtarını gir. Gerçek kullanım ücretli olabilir.

Yerel Ollama bağlantısı

Model telefonda değil, aynı güvenilir Wi-Fi ağına bağlı bilgisayarda çalışır. Ollama sunucusunu o bilgisayarda başlat; bilgisayarın yerel IP adresini yaz.

Yerel HTTP trafiği yalnızca güvendiğin ağda kullanılmalı. Bu ayar telefonuna model indirmez ve Ollama kurmaz.
