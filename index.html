Şifreli tam yedek

Yedek dosyasını cihazında AES-256-GCM ile şifrele. Aynı parola olmadan dosya açılamaz; parolayı unutursan kurtarma yolu yok. Bu özellik indirilen yedeği şifreler, tarayıcıdaki aktif kayıtları değil.

Parola sunucuya gönderilmez ve yedekte saklanmaz. API anahtarları yedeğe dahil edilmez. Normal JSON yedeği hâlâ şifresizdir; hassas kayıtlar için şifreli seçeneği kullan.

Proje verileri / gizlilik

Proje notları, sohbet geçmişi ve prompt eklentileri bu cihazda saklanır. Yedekler API anahtarlarını içermez. Sohbeti gerçek modele gönderdiğinde, yazdığın içerik seçili sağlayıcıya iletilir.
