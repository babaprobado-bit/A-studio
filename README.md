# AI Studio Alpha 1 — Android demo\n\nThis repository is a fork of [benbam-commits/A-studio](https://github.com/benbam-commits/A-studio). The demo source is in `AI-Studio-Alpha-1-Mobile-Demo-Source.zip`.\n\n## Build the APK\n\n1. Open the **Actions** tab.\n2. Choose **Build Android Demo APK**.\n3. Click **Run workflow** on the `main` branch.\n4. When the run completes successfully, open the run and download the `AI-Studio-Alpha-1-Demo-APK` artifact. Extract `app-debug.apk` from the artifact ZIP.\n\n## Limits\n\nThis is a UI/interaction prototype with locally generated example replies. It does not call real GPT, Claude, Gemini, or LocalCoder models, and it does not request or store API keys. A real provider connection is a later step; do not place secret API keys inside an APK.\n
